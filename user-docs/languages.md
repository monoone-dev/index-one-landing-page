IndexOne can write your notes in the language you choose, whatever language the meeting was in, and translate a meeting's note and transcript afterwards. The original is never changed. Live captions can be translated while you record. The Languages plugin adds a second copy of every note, a language button on each meeting and a glossary.

## The language of your notes

Settings › Notes › **Notes language** sets the language Ivy writes notes in:

- **Auto — match the meeting**: the whole note, headings included, is written in the language spoken in the meeting.
- A language: every note is written in that language, whatever was spoken.

This setting is available without the plugin. Transcription keeps the language it detected, or the one you set in Settings › Transcription.

Settings › Notes also has a **Workspace glossary**: one spelling per line, with optional aliases after an equals sign, so names come out the same way in every note.

## Translate a meeting

Any meeting with a note or transcript can be translated into English, Polish, German, Spanish, French, Italian, Portuguese, Ukrainian, Dutch, Chinese or Japanese.

1. Open the meeting's note or transcript.
2. In the translation bar, pick a language and choose **Translate**.
3. When it is done, a switch moves between **Original** and each translation.

- Translations are read-only. Switch to Original to edit the note.
- In a translated transcript, **Show original** puts the original line under each translated one.
- When the original changes, its translation is marked **Outdated**. **Re-translate** brings it up to date.
- Each language can be deleted on its own with the trash button.
- Translations are kept with the meeting and locked and unlocked with its folder.

Translation uses the AI chosen for the workspace in Settings › AI Models, with the same privacy settings and redaction as notes.

## Live translation

During a recording, open the **Translate** menu at the top of the Live transcript panel and choose a language. Each caption line gets its translation underneath. Choose **Translate: Off** to stop.

With an on-device AI, live translation can't run next to live captions. IndexOne then says so, and the final transcript is translated after you stop recording instead.

## The Languages plugin

The free Languages plugin works on the Mac and on the web, for yourself or for a whole organization. Install it from **Plugins** in the left rail; you need to be signed in. See [Plugins](/docs/plugins/).

Its settings are in Settings, under Plugins › Languages:

| Setting | What it does |
| --- | --- |
| Notes language | The same setting as Settings › Notes. |
| Also write every note in | A second copy of each note, written at the same time in another language. Choose None to turn it off. |
| Quick languages | The languages listed first when you translate. |
| Translate the transcript too | Each transcript line gets its translation, with the original next to it. |
| Glossary | Names and terms Ivy keeps as they are or translates your way. |

### Per recording

The Record screen gets a **Note language** row. It sets the language of this one recording's note and shows what you usually use.

### On a meeting

The plugin adds a language button to the note:

- **Read in** lists the original and every language the meeting has, including your second copy.
- **Translate to another language…** translates the meeting later. The new language is added to the button, and you can translate the transcript as well.
- **Compare with original** shows a translation and the original side by side.

A banner over a translated note says which language it was translated from. A translation follows edits of the original and updates when it changes.

### Glossary

Use **Add term** to add a name or term. For each one, choose to keep it as it is (**Never translate**) or give the word to use in a language. Translations show "glossary applied" when it was used.

### In an organization

Owners and admins set languages for the whole organization in its settings:

- **Notes language** replaces members' own setting inside the organization. Members see "Notes in (language) — set by (organization)" in their own settings.
- **Also write every note in** adds a second copy for the whole organization.
- **Members can translate for themselves** decides whether members can add their own translations.
- The organization can keep its own glossary, used together with yours.

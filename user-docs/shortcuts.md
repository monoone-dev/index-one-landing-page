IndexOne keeps its shortcuts short and predictable. Only one works from anywhere on your Mac; the rest work inside the IndexOne window. Where a table says ⌘, the Control key works too.

## Global

| Shortcut | What it does |
| --- | --- |
| ⌘⇧R | Shows or hides the floating recorder bar, from any app. It is also in the menu-bar menu as **Recorder bar**. |

This is the only shortcut IndexOne registers system-wide.

## In the app

| Shortcut | What it does |
| --- | --- |
| ⌘K | Opens or closes quick search, with a Search and an Ask Ivy mode |
| ⌘N or ⌘T | Creates a new note. In On this Mac it opens the create panel with Note chosen; in Personal or an organization it opens a blank note straight away. |
| ⌘W | Closes the current tab |
| Esc | Closes quick search, Settings or whatever is open |
| ⌘R | On the Record screen: starts a recording, or stops it and creates the note |
| ⌘↩ | In the move picker: confirms the destination. In Smart organize: generates the preview. |

## In the note editor

| Shortcut | What it does |
| --- | --- |
| ⌘B | Bold |
| ⌘I | Italic |
| ⌘⇧X | Strikethrough |
| ⌘⇧9 | Checklist item |
| ⌘1, ⌘2, ⌘3 | Heading level 1, 2 or 3 |
| / at the start of a line | Opens the slash menu, which includes an Ask Ivy entry |
| ↑ and ↓, then ↩ or Tab | Move through the slash menu or the link picker, then insert |
| [[ | Opens the link picker, to link another note |
| Esc | Closes the slash menu, the link picker or the selection bubble |
| ⌘V | Pastes a screenshot, an image or another file into the note |

## Ask Ivy about a selection

Select a passage in a note or a meeting note, and an Ask Ivy button appears beside it. Press ⌘J to open it from the keyboard. It leads to the Ivy menu's actions, which you can trim in Settings › Ivy. See [Notes](/docs/notes/).

## File previews

| Shortcut | What it does |
| --- | --- |
| ← and → | Previous or next file |
| ⌘F | Find in a document |
| Esc | Closes the preview |

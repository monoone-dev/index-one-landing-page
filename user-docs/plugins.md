Plugins add features to IndexOne, for you or for a whole organization. They have their own screen, open from the left rail, and each one works only in the places you install it.

## The Plugins screen

Open it with the **Plugins** button near the bottom of the left rail. It has two views:

- **Discover** lists everything you can install, with a filter for all plugins or Ivy skills and categories such as Recording, AI & notes, Integrations and For teams. Open a plugin to read what it does, see its screenshots, what changes in IndexOne, its permissions and what happens if you uninstall it.
- **Installed** lists the plugins you have, with where each one is installed.

A plugin's page also shows where it is installed, by whom and when, with a link to manage it.

Plugins moved out of Settings into this screen in [3.18](/changelog/#v3.18.0). Old links to plugins in Settings open the new screen.

Ivy skills are listed on the same screen; see [Ivy skills](/docs/ivy-skills/).

## You need to be signed in

Plugins need your IndexOne account. Signed out, the Plugins screen asks you to sign in. Plugins turn on as soon as you are signed in, and once installed they keep working when your Mac is offline.

If IndexOne cannot confirm a plugin with your account, it says "Couldn't turn on this plugin." with a **Try again** button. Check your connection and try again.

## Choose where a plugin works

When you install a plugin, IndexOne asks where it should work:

- **On this Mac**
- **Personal**
- one of your **organizations**

A plugin runs only where it is installed, and each place has its own settings. The Record screen uses the plugins of the place you record to, and a meeting uses the plugins of the place it lives in. You can add a plugin to more places later. When you switch organization, the plugins and settings of the previous one are gone at once.

Only an organization's owners and admins can install or change plugins for that organization. Other members see "Only admins can install for an organization". A plugin that also works for one person can still be installed in your own places.

## The plugins in 3.19

All three are free.

| Plugin | Where | What it does |
| --- | --- | --- |
| Screen recording | For you or an organization, on the Mac and the web | Records your screen with a meeting and adds frames from it to the note. Until it is installed, the screen recording controls are hidden. On the Mac, voice + screen needs macOS 14 or later. See [Screen recording](/docs/screen-recording/). |
| Languages | For you or an organization, on the Mac and the web | Writes notes in the language you choose, adds a second language, translates meetings later and keeps a glossary. See [Languages](/docs/languages/). |
| Meeting bot | Organizations only; runs on IndexOne on the web | A bot that joins Google Meet calls for the organization. You can install it from the Mac, but it works on the web. |

## Plugin settings stay in Settings

A plugin's own settings are in Settings, not on the Plugins screen. When a plugin with settings is on, Settings gets a **Plugins** group with a section named after it, such as Screen recording or Languages. Each section belongs to the place you are working in.

An organization's plugin settings are a tab in Settings › Organization, which owners and admins manage.

## Uninstall a plugin

Open the plugin on the Plugins screen and choose **Uninstall**. Its page says beforehand what happens if you uninstall it in that place.

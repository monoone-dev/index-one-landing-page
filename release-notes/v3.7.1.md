*Originally released on 2026-10-19.*

A recording that IndexOne could not turn into a note is no longer stuck. Long recordings that reached the four-hour limit now finish properly, and any recording kept after a failure can be recovered or saved as a sound file.

### Recordings

- Recordings that reached the four-hour limit, or were interrupted, now become notes again. Before this release, a tiny mismatch in the last moments of the audio could reject the whole recording.
- A meeting that ended in an error but still has its audio shows **Recover recording**. IndexOne transcribes it and writes the note, and if something still goes wrong, it shows the reason.
- **Settings → Storage → Recordings to recover** lists kept recordings that have no meeting. You can recover each one into a meeting or export it as a WAV file. Exporting never changes the original.
- A failed recovery never deletes or changes your audio. It is removed only after a note is made.

### Tags

- Tags you add to meetings now appear in the local MCP, separate from the tags IndexOne suggests, and backups keep them.

### Downloads

The DMG is signed and notarized by Apple. It runs on Apple Silicon and Intel Macs with macOS 13.4 or later. Check it against `SHA256SUMS.txt` with `shasum -a 256 -c SHA256SUMS.txt`.

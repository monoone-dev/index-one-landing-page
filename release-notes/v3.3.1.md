*Originally released on 2026-10-10.*

Codex writes notes again after the latest Codex CLI update.

### Fixes

- Codex CLI 0.162 is supported. After Codex updated to 0.162, the Cloud AI mode showed "Codex is not available on this Mac" and stopped writing notes; it now works with 0.146, 0.160 and 0.162, with the same tool and network isolation as before.

### Downloads

The DMG is signed and notarized by Apple and runs on Apple Silicon and Intel Macs with macOS 13.4 or later. Verify it against `SHA256SUMS.txt` with `shasum -a 256 -c SHA256SUMS.txt`.

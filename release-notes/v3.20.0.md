*Originally released on 2026-11-15.*

Write your own Ivy skills, try them on notes and discover skills shared by the community. This release also gives IndexOne the icon's blue as its default accent.

### Your skills and the community

- Create and manage your own skills in My skills, including private and disabled skills.
- Try a skill on an account note before turning it on, without changing the original note.
- Share a skill by link or on the community shelf, and review its instructions before installing it.
- Review newer skill versions, rate or report shared skills, and submit your own to the store.
- See verified badges, install counts and ratings on skill pages.

### Appearance and reliability

- The icon's blue is now the default accent.
- Web requests are better bounded to respect the account's rate limit.

### Downloads

The DMG is signed and notarized by Apple. It runs on Apple Silicon Macs (M1 or later) with macOS 13.4 or later. Intel Macs are no longer supported. Check the download against `SHA256SUMS.txt` with `shasum -a 256 -c SHA256SUMS.txt`. If you run 3.8.0 or later on a supported Mac, IndexOne offers the update itself.

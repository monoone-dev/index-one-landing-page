*Originally released on 2026-08-27.*

IndexOne 2.0 is a bigger release than the version number changes usually are: one hierarchy for everything you keep, three new surfaces, and a way to bring your existing notes with you.

Signed, notarized, universal (Apple Silicon + Intel). Everything still records, transcribes and summarises **on your Mac**, into plain Markdown you own.

## Spaces — one tree for everything

The separate Meetings and Notes folders are gone. There is now a single tree — **Spaces › folders › your recordings and notes** — behind a persistent icon rail with a contextual panel. Lock a Space and everything inside it seals with it, including the folders underneath.

## Dashboards

Compose a board out of what you already have: notes, recordings, documents, people, promise ledgers and reminders. Read it through **Brief / Overview / Commitments / Sources / People** lenses, or pin a **living answer** — a question IndexOne keeps up to date and withholds the moment its sources stop being readable.

You can also ask a board directly, grounded only in what is on it.

## Imports — bring your existing notes

**Settings → Imports** pulls in a Notion export, an Obsidian vault, or your Apple Notes library. Entirely offline: no API token, no account, no network call. Every import is a dry run first, so you see exactly how many notes are new and how many will update.

Everything lands in its own labelled Space — *Imported from Notion*, *Imported from Obsidian*, *Imported from Apple Notes* — so it never mixes into your existing notes. Re-run an import and it updates in place instead of duplicating.

## Ask remembers

Vault, note and meeting conversations now persist, each with its own history browser. A conversation disappears the instant any folder it drew on stops being readable.

## Shared Ivy: per-document permissions

The author picks **View only** or **Can edit** for each shared document. Collaborative editing is now crash-safe against concurrent edits.

## Tasks

Shared work inside a Shared Ivy organization — assignees, due dates, subtasks, images, and the same permissions. Tasks live inside an org, so they need a signed-in account; the rest of IndexOne does not.

## Also

- One unified model picker across every AI surface, with a free-text model id — so a model released after this build still works.
- Better facts from on-device Ivy, and a new `list_workspace_hierarchy` tool so an assistant knows where things live.
- Reminders got quick presets that show the exact time they resolve to, and meeting follow-ups moved above the fold.

## Fixes worth naming

- **Locked content could leak to connected assistants.** A board filed in a locked folder disclosed its title and shape over the local MCP surface. Locking a project did not always re-close a folder inside it you had opened this session, and "Lock again" did not cascade. All three are fixed, each with a regression test.
- **Ask history was being erased.** For anyone with at least one locked folder, durable Ask history was cleared on every app launch. Now only conversations that actually drew on the folders being sealed are removed.
- **Importing a second Obsidian vault could overwrite notes** from the first when both contained the same relative path. Note identity is now vault-scoped.
- **Sharing by link and between IndexOne apps** works again — the relay has been updated to match this client.

---

**Install:** download the DMG, open it, drag IndexOne to Applications. It is notarized, so it opens normally — no right-click, no Gatekeeper warning.

**Upgrading from 1.x:** your database migrates in place and your existing notes, meetings and folders appear in the new Spaces tree. Nothing is rewritten or moved in your Obsidian vault.

*Originally released on 2026-09-03.*

Murmur 2.4.0 closes a full production-readiness audit: 31 changes, most of them things that were
wrong rather than things that were missing.

## Your data stays yours — even when it changes hands

Four fixes here, and the first two matter most if you share a Workspace with anyone.

- **Removing someone from an org now actually removes them.** The org content key is rotated when a
  member is removed, so a former member's copy of the key stops opening anything published
  afterwards. Previously the key survived the removal.
- **An org invite pins the key it was accepted with** (trust-on-first-use). A relay that swapped the
  public key mid-flight can no longer make you encrypt to a key you never agreed to.
- **The database key is never re-minted over an existing database.** A key mismatch now fails loudly
  and leaves your data alone instead of creating a second key that cannot open it.
- **Deleting a note purges its Ask history with it.** Answers derived from a deleted note no longer
  linger in chat history — and moving a note between Workspaces re-scopes it correctly.

## Locking a folder no longer costs you anything

Manual links between notes and meetings, and the fact ledger the brain builds, both used to be
dropped by a lock → unlock cycle. They now survive it intact. Restoring a note from the trash brings
back its links, mentions and facts too, rather than a note stripped of everything it knew.

## Transcription

- **Words stopped falling into the gaps.** Long recordings are decoded in windows, and those windows
  were read back-to-back — so a word straddling a boundary could be lost. The windows now overlap and
  a single owner is chosen for each boundary.
- **The language stops flipping mid-recording.** The language was detected per window, so a quiet
  stretch in a Polish meeting could hand the rest of it to English. It is now detected once and
  pinned.
- **Retry is a button.** A recording that failed to transcribe can be retried from the meeting itself
  instead of needing a restart.
- **If system audio dies mid-meeting, Murmur says so.** The far side of a call going silent used to
  be indistinguishable from nobody talking.

## Speed

Opening the app and browsing long lists no longer blocks on the database. List reads moved off the
main thread, and `/library` and `/notes` render a window of rows rather than all of them.

## New

- **Update checks are opt-in and logged.** Murmur asks before it ever contacts GitHub to look for a
  new version, and the request is recorded in the egress ledger like any other outbound call.
- **A diagnostics bundle you can actually send.** One button collects logs and environment details
  with no note content, no transcripts and no titles in it — the command that builds it has no
  access to the database at all, which is what makes that a guarantee rather than a promise.
- **Logs are kept for 7 days** with a size ceiling, instead of growing without bound.

## Consistency

One name per level of the hierarchy. The same thing used to be a "space" in one menu, a "Workspace"
in the sheet that created it and a "container" in the view of it — sometimes within one session.

*Originally released on 2026-10-16.*

A fix for turning on screen recording.

### Screen recording

- Open System Settings in Settings → Screen Recording, and in the source picker, now asks macOS for access first, so IndexOne appears in the Screen & System Audio Recording list by itself and you only turn on its switch. If macOS already allows it, the status updates and System Settings stays closed.

### Downloads

The DMG is signed and notarized by Apple and runs on Apple Silicon and Intel Macs with macOS 13.4 or later. Verify it against `SHA256SUMS.txt` with `shasum -a 256 -c SHA256SUMS.txt`.

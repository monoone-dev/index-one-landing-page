*Originally released on 2026-11-05.*

Move your folders between IndexOne on your Mac and IndexOne on the web.

### Copy folders to the web

- In Settings › Imports, "Copy to IndexOne on the web" saves the folders you pick to one `.indexone.tar` file.
- Upload that file to IndexOne on the web to bring your notes, meetings, documents and audio there.

### Import from the web

- In Settings › Imports, "Import from IndexOne on the web" opens an export from the web and adds each space as a folder on your Mac.
- Before anything is written, IndexOne checks the whole file and shows what each space holds and how much of it you already have. Pick a new folder or an existing one for each space.
- IndexOne refuses a damaged or altered file before it writes anything.

### Downloads

The DMG is signed and notarized by Apple. It runs on Apple Silicon and Intel Macs with macOS 13.4 or later. Check it against `SHA256SUMS.txt` with `shasum -a 256 -c SHA256SUMS.txt`. If you run 3.8.0 or later, IndexOne offers this update itself.

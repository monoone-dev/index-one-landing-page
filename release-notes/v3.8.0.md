*Originally released on 2026-10-30.*

IndexOne now updates itself: new versions install from inside the app.

### Updates

- IndexOne checks for a new version and offers to install it. It downloads the update, checks its signature, installs it and restarts when you agree, so you no longer download each release by hand.
- This version is the last one you install by hand; later versions arrive in the app.

### Organization sharing

- Sharing now connects to IndexOne's new server address. Your shared documents and organizations stay as they were, and there is nothing to change.

### Downloads

The DMG is signed and notarized by Apple. It runs on Apple Silicon and Intel Macs with macOS 13.4 or later. Check it against `SHA256SUMS.txt` with `shasum -a 256 -c SHA256SUMS.txt`.

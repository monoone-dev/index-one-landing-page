*Originally released on 2026-11-14.*

Ivy skills help shape your notes and answers, with a shelf in Plugins and shortcuts where you work. This release also improves plugin availability and several parts of IndexOne on the web.

### Ivy skills

- Sign in to browse Ivy skills in Plugins and open a skill to see its details.
- Choose skills from the Ivy window, notes and the recording bar.
- Skills guide desktop notes and answers with Ivy in the cloud.

### Plugins and the web

- Plugins correctly recognize account permissions and show when a plugin could not turn on.
- The web plugins screen and Ivy skills have translated text.
- Screen previews recover correctly and make fewer duplicate requests.
- Opening task details shows the task's saved status.
- Updated the network connection library with a security fix.

### Downloads

The DMG is signed and notarized by Apple. It runs on Apple Silicon Macs (M1 or later) with macOS 13.4 or later. Intel Macs are no longer supported. Check the download against `SHA256SUMS.txt` with `shasum -a 256 -c SHA256SUMS.txt`. If you run 3.8.0 or later on a supported Mac, IndexOne offers the update itself.

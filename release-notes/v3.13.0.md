*Originally released on 2026-11-08.*

IndexOne now has plugins. Screen recording is the first one.

### Plugins

- Settings has a new Plugins page. Browse the plugins, read what each one does, see its screenshots and install it for yourself or for your organization.
- Only an organization's admins can install or change plugins for that organization.
- Plugins need your IndexOne account. Once installed, they keep working when your Mac is offline.

### Screen recording is a plugin

- Screen recording now comes as the free Screen recording plugin. Install it from Settings › Plugins to record your screen with a meeting and keep its frames in the note.
- Until you install it, the screen recording controls are hidden.

### Anonymous usage statistics

- IndexOne sends one small anonymous message a day: a random install ID, the app version, the macOS version, the chip type, the language and whether you are signed in. No notes, recordings or names.
- Turn it off in Settings › Privacy with "Send anonymous usage statistics". When it is off, nothing is sent.

### Fixes

- On a phone, IndexOne on the web shows the participants' notice right under Start recording, so you can start without scrolling.

### Downloads

The DMG is signed and notarized by Apple. It runs on Apple Silicon and Intel Macs with macOS 13.4 or later. Check it against `SHA256SUMS.txt` with `shasum -a 256 -c SHA256SUMS.txt`. If you run 3.8.0 or later, IndexOne offers this update itself.

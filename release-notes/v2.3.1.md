*Originally released on 2026-09-01.*

A bug-fix release for one report: the Organization panel in Settings hung on
**"Loading organizations…"** and never recovered, and once it did load, sharing to
an org had silently stopped working while "Sync now" kept answering
**"Synced — up to date."**

That turned out to be four separate defects, three of which existed only to hide
the fourth.

### The panel can no longer hang

Refreshing the org list waited on an internal sharing lock with no time limit. If
anything held that lock, the panel waited forever — and signing out did not help,
because the lock lives in the running app, so only a restart cleared it. The wait
is now bounded: if a sharing operation really is in flight, the panel says so and
shows your locally-known orgs instead of spinning.

### "Sync now" stops claiming success over a failure

A manual sync also republishes your shared folders. When that leg failed it was
written to a log file and otherwise discarded, so the sync returned the same
empty result a genuinely clean sync returns — and the panel renders an empty
result as "up to date". A failure there now reaches you, and the message names
the actual error instead of always guessing that a key had not been granted yet.

### A signed-out session says so

An expired session was swallowed in three places and rendered as an empty panel,
which looks exactly like being offline. Only a genuine sign-in failure is now
surfaced; offline and not-signed-in stay the quiet no-op they should be.

### Failures name themselves

Every org failure was logged as the single unhelpful word `unavailable`, which is
why the original report took a full investigation to place. The log line now
carries the specific failure code, so a repeating background failure can be read
directly rather than reconstructed.

---

Nothing else changed: no data migration, no format change, no new permissions.
If org sharing was failing for you, this build will tell you why in the developer
log — and in most cases the fix is a single click in Settings.

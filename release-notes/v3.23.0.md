*Originally released on 2026-11-23.*

### Plans and usage

- Plans no longer show hourly transcription allowances. Paid plans include transcription under fair use, as described in the terms.
- The recording bar, the usage card and the plan comparison no longer count down transcription hours.

### Recording

- The recording view has more room at the bottom, and the note box sits lower so it no longer covers the controls.
- "Process later" is now a compact icon button next to the other recording controls.

### Look and feel

- Sidebar icons are coloured by item type again, so spaces, meetings and notes are easier to tell apart.
- Settings, file preview and removed-skill windows use the same dialog style as the rest of the app.

### Downloads

IndexOne requires an Apple Silicon Mac (M1 or later) with macOS 13.4 or later.

*Originally released on 2026-11-12.*

Local AI server fixes: Test connection shows the real result, a failed test says why, and servers that need an API key, such as oMLX, now work. Notes from long meetings and in other languages are more reliable.

### Local AI server

- Test connection now shows the model and response time when the server answers. Before, it could show an empty "Connected" line next to an error, even when the server worked.
- When something goes wrong, IndexOne now says what happened: the server needs an API key, the key was refused, the server does not know this model, it ran out of memory for the model, it took too long to answer, or nothing answered at that address. Before, every failure said "Please try again."
- A new optional API key field is for servers that ask for one, such as oMLX with an API key set. The key is stored in your Mac's Keychain and sent only to the address you entered. If you change the address, enter the key again.
- oMLX usually listens at `http://localhost:8000`.

### Notes and answers

- Notes from a long meeting written on this Mac now cover the end of the meeting too.
- Notes, facts and answers stay in the meeting's language, and transcription keeps the language it detected.
- When IndexOne masks personal details before sending text to a cloud model, dates and amounts are now kept, so notes keep them as well.

### Downloads

The DMG is signed and notarized by Apple. It runs on Apple Silicon and Intel Macs with macOS 13.4 or later. Check it against `SHA256SUMS.txt` with `shasum -a 256 -c SHA256SUMS.txt`. If you run 3.8.0 or later, IndexOne offers this update itself.
